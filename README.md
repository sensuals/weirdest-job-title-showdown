Entry for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. The program writes one job title, 60 characters or fewer, to `/output/entry.txt`: "Lead Negotiator for Cats Who Refuse to Move" (43 characters). It reads like a real corporate job with one hilariously specific twist: the other party at the table is a cat that refuses to move.

## Run it

```sh
python3 main.py
```

This writes the title to `/output/entry.txt`.
